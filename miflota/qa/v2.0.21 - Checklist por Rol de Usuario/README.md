# MiFlota v2.0.21 - Checklist por Rol de Usuario

## Mejoras y novedades de esta versión

- Se agrega soporte de checklist diferenciado según el rol del usuario: conductor, supervisor (Nivel 2) y contratista.
- El botón de acceso al checklist ahora se muestra condicionalmente según el rol que tenga asignado el usuario autenticado.
- Se agrega el parámetro `userType` al endpoint de encuesta para que la API devuelva el formulario correspondiente al rol del usuario.
