# MiCamión

App móvil de gestión logística para conductores de camión. Digitaliza el ciclo completo de transporte de carga: citación → acreditación (fatiga + checklist + GPS) → cola de asignación → orden de carga → despacho → entrega con firma digital.

**Stack:** Flutter (Android) · Backend Symfony 7.4 · Integraciones: JDE, UNIGIS, Angelis, MiFlota, Visión
