# Mi Seguridad v2.2.6 - Evaluación de Documentos

## Mejora

Se mejoró el módulo de consulta de documentación de MiSeguridad, permitiendo buscar trabajadores mediante RUT y vehículos por patente, además de incorporar el escaneo de códigos QR. La información ahora presenta de manera más clara el estado de carga y aprobación de cada documento, junto con su fecha de vencimiento en formato DD/MM/AAAA, destacando aquellos próximos a vencer.
