# Mi Seguridad v2.2.7 - Asistencia a charla

> ⚠️ **Este build está apuntando a PRODUCCIÓN.**

## Mejora

Se incorporó un nuevo botón de **Asistencia a charla**, ubicado justo debajo del menú principal y destacado en color verde claro para que sea fácil de encontrar. Al presionarlo, la aplicación abre el navegador y lleva directamente al registro de asistencia, permitiendo a los trabajadores confirmar su participación en las charlas de seguridad de forma rápida y sencilla, sin pasos adicionales.
