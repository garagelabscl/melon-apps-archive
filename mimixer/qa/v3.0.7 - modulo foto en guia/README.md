# Mimixer v3.0.7 - Foto de guía física firmada

## Mejoras y novedades de esta versión


- Se agrega la opción **“Tomar foto a la Guía”** en la pantalla de firma digital.
- La opción se muestra sólo cuando la obra/guía tiene habilitado `physical_signature_photo_enabled`.
- El usuario puede:
  - Tomar una foto de la guía física firmada.
  - Revisar la previsualización antes de enviarla.
  - Confirmar el envío.
  - Reintentar la captura.
  - Cancelar la foto capturada.
- La foto se comprime antes de enviarse para evitar payloads demasiado grandes.
- Si el dispositivo está sin conexión, la foto queda almacenada localmente y se sincroniza cuando vuelva Internet.
