# Mimixer v3.0.6 - Módulo Evaluación

## Mejoras y novedades de esta versión

- Se agrega nuevo módulo de evaluación de usuarios con sistema de puntuación por estrellas.
- Se agrega vista de desempeño del mes actual.
- Se agrega vista de puntuación de los últimos meses.
- Se agrega vista de puntuación por día de los últimos 2 meses, con opción de ver detalle por día.
- Al ingresar al detalle de un día se listan todas las guías del día con su puntuación según cumplimiento.
