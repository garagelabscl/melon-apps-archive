


# Mimixer v3.0.1 - 236

## Mejoras y novedades de esta versión

- Se corrigió el bug que impedía enviar guías por correo electrónico desde la vista de guía.
- Se corrigió el bug que ocultaba el botón "Utilizar este dispositivo" en la solicitud de firma digital.
- Se mejoró la experiencia de usuario en el login, mostrando el cursor correctamente en los campos de usuario y contraseña para una interacción más intuitiva.
- Se optimizó el sistema de notificaciones push:
	- Ahora las notificaciones se eliminan correctamente al ser seleccionadas.
	- Se mejoró el apilamiento y la gestión de notificaciones pendientes.
	- Se ajustaron configuraciones para asegurar la recepción de notificaciones incluso con la app cerrada.
	- Se realizaron pruebas exitosas en dispositivos Android desde la versión 10 hasta la 16.
- Se actualizó la gestión de eventos de guías de despacho que se envían por Firebase.
